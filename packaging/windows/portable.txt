BD Launcher portable mode

While this file sits next to bd-launcher.exe, BD Launcher keeps its settings, its
download cache and its record of installed apps in the BDLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move BD Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\BD Launcher) instead.
If BDLauncherData can't be written (for example on a read-only drive), BD Launcher says
so and uses %APPDATA%\BD Launcher instead.
